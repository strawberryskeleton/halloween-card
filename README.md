# Halloween Card
a website to serve as a card to wish people on halloween

## Features
- ghost glow text
- floating ghost animation
- custom font + favicon

## Screenshot
![image](./assets/project_ss_update.png)

## Run Locally
1. clone the repo
2. run `index.html`
